Recruiter Dashboard Help

View Requests

When you click on "Recruiter", you will land on the Request List Page. Here, you can see the job requests added by the requester.

Manage Candidates

There are two dropdowns in the Request List page called "Candidate" and "Interview".

  • Add Candidate: Use this to add a candidate.
  • View Candidate: Use this to view the added candidate list.

Schedule Interviews

From the Request List page, in the action add button, you can add candidates from the general candidate list for a specific request. This candidate list gets fetched in the Requester Dashboard under "Selected Candidate".

To schedule an interview, click on the "Schedule Interview" button. This will redirect you to the Schedule Page. Here, you can schedule interviews for candidates. If you select the interview type as "Face to Face", it will ask for the location. For a "Video Interview", it will ask for a meeting link. An email will be sent to the candidate and the interviewer with the details.

Feedback

After the interview, the requester can give feedback under the popup using the "Add Feedback" button, which redirects to the Feedback Page. The feedback, score, and status of that round will be updated and fetched in the Recruiter Dashboard under the "Interview" dropdown in the Feedback Status List Page.
